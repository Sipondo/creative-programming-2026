What is a library?

A library is just extra code that someone else wrote and shared. You include it in your project with a script tag, just like you include p5.js itself. The library then gives you new functions and objects to use in your sketch. You’ve already been using a library this entire course – p5.js itself is a library!

  • A library is extra code that gives p5.js new abilities
  • We’ve used one before: p5js sound
  • You include it with a <script> tag in your HTML
  • Then you can use its new functions in your sketch
<html>
  <head>
    <script src="https://cdn.jsdelivr.net/npm/p5/lib/p5.min.js"></script>
    <!-- Add your library here -->
    <script src="https://the-library-url.js"></script>
  </head>
  <body>
    <script src="sketch.js"></script>
  </body>
</html>

Games and Physics

Why games and physics?

Games are one of the most engaging forms of interactive media. They combine visuals, interaction, and logic into one experience. Physics simulations make things feel real and satisfying – things bounce, fall, and collide. Even simple games can be incredibly fun to build and play.

  • Games are engaging but also hard to make
  • They combine visuals, interaction, and logic
  • Even simple games can be incredibly fun to build and play

What is p5play?

p5play is a game engine built on top of p5.js. It uses the Box2D physics engine under the hood, which is the same engine used by games like Angry Birds. It was designed by computer science teachers to be easy to learn, so it fits perfectly with what we’ve been doing in this course. You can make games, physics simulations, and interactive art with very little code.

  • A game engine built on p5.js
  • Powered by the Box2D physics engine (same as Angry Birds!)
  • Designed by CS teachers for beginners
  • Handles gravity, collisions, sprites, animation, input
  • p5play.org

Including p5play

p5play needs two files: planck.js (the physics engine) and p5play.js itself. You can either download them into your project folder or load them from the web. Downloading is preferred so your sketch works offline.

Download both files into your project folder (preferred):

  • planck.min.js
  • p5play.js
<script src="planck.min.js"></script>
<script src="p5play.js"></script>

Or load from the web:

<script src="https://p5play.org/v3/planck.min.js"></script>
<script src="https://p5play.org/v3/p5play.js"></script>

Sprites

The core concept in p5play is the Sprite. A Sprite is a game object with a position, size, and physics properties. You create one with new Sprite() and p5play automatically draws it and simulates physics for it. A single number for the size makes a circle; two numbers make a rectangle.

The building block of p5play is the Sprite:

function setup() {
  createCanvas(400, 400);

  // new Sprite(x, y, diameter) -- circle
  let ball = new Sprite(200, 100, 50);

  // new Sprite(x, y, width, height) -- rectangle
  let box = new Sprite(200, 300, 100, 50);
}
  • Sprites are automatically drawn
  • They have built-in physics – they fall, collide, and bounce

Gravity and bounciness

By default, sprites don’t have gravity. You turn it on by setting world.gravity.y to a positive number. You can make sprites bouncy by setting their bounciness property – 1 means perfectly bouncy, 0 means no bounce. A "static" sprite doesn’t move, which is perfect for floors and walls.

function setup() {
  createCanvas(400, 400);
  world.gravity.y = 10;

  let ball = new Sprite(200, 50, 40);
  ball.bounciness = 0.8;
  ball.color = "orange";

  // "static" sprites don't move
  let floor = new Sprite(200, 380, 400, 20, "static");
  floor.color = "darkgreen";
}
  • world.gravity.y = 10 – things fall down
  • bounciness from 0 (no bounce) to 1 (perfect bounce)
  • "static" sprites are fixed in place

Spawning on click

p5play has its own input system. mouse.presses() returns true on the frame the mouse is clicked. This makes it easy to spawn new sprites on click. Each new sprite gets physics automatically – it falls, collides with other sprites, and bounces off the floor.

What can you make?

  • Sprites/physics are super useful, even for non-games!
  • Platformer games – player sprite, platforms, enemies
  • Physics simulations – balls, chains, ragdolls
  • Interactive art – physics-driven compositions

Learn more: p5play.org/learn

Machine Learning

Why machine learning?

Machine learning is everywhere – from face filters on social media to motion capture in movies. But you don’t need to be a data scientist to use it. ml5.js makes it possible to use pre-trained models in your p5.js sketches with just a few lines of code. Imagine your sketch reacting to your hands, your body, or your face in real time.

  • Your sketch can see and react to the real world
  • Hand tracking, body detection, face recognition – all through the webcam
  • Opens up entirely new ways to interact with creative work
  • The “wow factor” is very high – even with simple code

What is ml5.js?

ml5.js brings machine learning to p5.js. It wraps TensorFlow.js and provides pre-trained models that you can use with just a few lines of code. The most impressive features for creative projects are the body and hand tracking models – they use your webcam to detect where your hands, face, or body are in real-time. No training needed!

  • Machine learning made easy for p5.js
  • Pre-trained models – no training needed
    • Models are the AI systems
  • Combine with your code to add surprising interactions
  • ml5js.org

Including ml5.js

ml5.js is a single file. Download it into your project folder or load it from the web. Note that ml5.js is quite large because it bundles TensorFlow.js.

Download into your project folder (preferred):

  • ml5.js
<script src="ml5.js"></script>

Or load from the web:

<script src="https://unpkg.com/ml5@1/dist/ml5.js"></script>

What models are available?

ml5.js comes with several pre-trained models. BodyPose detects 17 keypoints on a person’s body (nose, eyes, shoulders, elbows, wrists, etc.). HandPose detects 21 keypoints per hand. FaceMesh gives you 468 facial landmarks. These all work in real-time through the webcam.

  • BodyPose – body pose estimation
  • HandPose – hand tracking
  • FaceMesh – face detection
  • ImageClassifier – recognise objects in images
  • SoundClassifier – detect sounds
  • (NeuralNetwork – train your own model)

Dog breed classifier

This example combines two things: the Dog API from lecture 8 (to fetch a random dog image) and ml5’s ImageClassifier with MobileNet (to guess the breed). Each time you click, it fetches a new dog and classifies it. MobileNet knows over 100 dog breeds, so it often gets impressively close!

Breaking it down

This sketch combines an API call (from lecture 8) with machine learning. First we fetch a random dog URL from the Dog API, then load that image, then pass it to ml5’s classifier. The callback pattern is the same as many ml5 models: call a function, pass a callback, handle the results. MobileNet can recognise over 1000 categories including many dog breeds.

  1. ml5.imageClassifier("MobileNet") – load the AI model
  2. classifier.classify(dogImage, gotResult) – asks the model: “what breed?”
  3. gotResult(results) – callback function once the model is done thinking

Hand and body tracking

Image classification is just the start. ml5.js also has models that work with your webcam in real-time: HandPose tracks 21 points on each hand, BodyPose tracks your full body, and FaceMesh maps 468 points on your face. These are more advanced but follow the same pattern – load the model, start detection, handle results in a callback.

ml5.js can also track your body in real-time via the webcam:

  • HandPose – 21 keypoints per hand (finger tips, knuckles, wrist)
  • BodyPose – 17 body keypoints (nose, shoulders, elbows, wrists, …)
  • FaceMesh – 468 facial landmarks

Same pattern: load model, start detection, draw the keypoints.

These need webcam access – try them locally!

What can you make?

  • Air drawing – draw on screen with your finger
  • Gesture controls – wave to change colours, pinch to zoom
  • Body-controlled games – move a character with your body
  • Face filters – overlay graphics on facial landmarks
  • Interactive installations – art that reacts to the viewer

Learn more: ml5js.org

Generative Text

Why generative text?

Words are everywhere in creative work – from poetry to chatbots, from interactive fiction to generative art. What if your sketch could write its own poetry, find rhymes, or generate stories? RiTa.js brings the power of language to p5.js.

  • Words are a powerful creative medium – not just visuals!
  • Generative text creates unique output every time
  • Grammars let you define the structure of language
  • Great for poetry, stories, chatbots, and text-based art

What is RiTa.js?

RiTa is a toolkit for computational writing and generative text. It’s been around for a long time and is used by digital poets, artists, and writers. It gives you tools to generate text from grammars, find rhymes, count syllables, and identify parts of speech. If your project involves words, stories, or language in any way, RiTa is your friend.

  • A toolkit for computational writing
  • Generate text from grammars
  • Analyse language: rhymes, syllables, parts of speech
  • Create Markov chain text (generated text)
  • Used by digital poets and artists
  • rednoise.org/rita

Including RiTa.js

Download into your project folder (preferred):

  • rita.min.js
<script src="rita.min.js"></script>

Or load from the web:

<script src="https://cdn.jsdelivr.net/npm/rita"></script>

Grammars

A grammar is a set of rules for generating text. You define categories (like adjective, noun, verb) with a list of options each. Then you define a pattern that combines them. RiTa picks randomly from each category to generate unique text every time. This is called a context-free grammar – a fundamental concept in computational linguistics.

A grammar defines rules for generating text:

let grammar = RiTa.grammar({
  start: "The $adj $noun $verb",
  adj: "[ golden | silent | broken | dancing | ancient ]",
  noun: "[ river | shadow | dream | mirror | forest ]",
  verb: "[ flows | drifts | whispers | fades | glows ]"
});

let sentence = grammar.expand();
// e.g. "The silent dream whispers"
// e.g. "The golden river flows"
  • $adj gets replaced by a random choice from the adj list
  • Call grammar.expand() to generate a new sentence each time

Generative poem

This example creates a three-line poem generator. Each time you click, it generates a new poem using the grammar rules. The grammar defines the structure of each line, and RiTa fills in the blanks randomly. You get a different poem every time.

Language analysis

Beyond generating text, RiTa can also analyse existing text. You can find words that rhyme, count syllables, and identify parts of speech. This is useful for creating constrained poetry (like haiku with syllable counting) or for finding creative word connections.

RiTa can also analyse language:

// Find rhymes
let rhymes = RiTa.rhymes("cat");
// ["bat", "hat", "sat", "flat", ...]

// Count syllables
let count = RiTa.syllables("creativity");
// "kri-ey-tiv-ih-tiy" (5 syllables)

// Get part of speech
let pos = RiTa.pos("The cat sat");
// ["dt", "nn", "vbd"] (determiner, noun, verb-past-tense)

What can you make?

  • Poetry generators – grammars that write poems
  • Interactive fiction – stories that change each reading
  • Text visualisations – words as visual elements
  • Chatbot personalities – grammar-driven dialogue
  • Concrete poetry – where the shape of text matters

Learn more: rednoise.org/rita

Animated Drawing

Why animated drawing?

Animation brings things to life. From hand-drawn cartoons to motion graphics on the web, the idea of things moving and appearing over time is fundamental to creative media. What if your shapes could draw themselves, like someone is sketching them in real time?

  • Static shapes appear instantly – animated ones tell a story
  • Watching something draw itself feels alive and engaging
  • Great for presentations, infographics, and storytelling
  • Adds polish to any sketch with minimal effort

What is p5.animS?

p5.animS is a small library that animates the drawing process of p5.js shapes. Instead of a circle appearing instantly, it progressively draws itself over a number of frames – like watching someone draw it by hand. The API mirrors the standard p5.js shape functions, so it’s very easy to pick up. You just add an ID (to track the animation) and a duration (in frames).

  • Animates the drawing process of p5.js shapes
  • Shapes progressively draw themselves over time
  • Like watching someone draw them by hand
  • Same function names as p5.js, with two extra parameters
  • github.com/wixette/p5.animS

Including p5.animS

Download into your project folder (preferred):

  • p5.anims.min.js
<script src="p5.anims.min.js"></script>

Or load from the web:

<script src="https://cdn.jsdelivr.net/npm/p5.anims@0.0.7/build/p5.anims.min.js"></script>

Animated circle

The simplest example: an animated circle. The first parameter is a unique ID string – this lets p5.animS track the animation state across draw() calls. The second parameter is the duration in frames. The rest of the parameters are the same as the regular p5.js circle() function. Click the mouse to replay the animation with animS.reset().

function draw() {
  background(220);
// animS.circle(id, duration, x, y, diameter)
  animS.circle('c1', 60, 300, 200, 150);
}

function mouseClicked() {
  animS.reset();  // replay all animations
}
  • First parameter: a unique ID (any string)
  • Second parameter: duration in frames
  • Rest: same as regular circle()

Multiple animated shapes

You can animate multiple shapes at once – each one needs its own unique ID. They all start animating from the first frame, so you see them all drawing simultaneously. The library supports all the basic p5.js shapes: circle, ellipse, rect, line, triangle, arc, and more.

Available shapes

Standard p5.js p5.animS equivalent
circle(x, y, d) animS.circle(id, dur, x, y, d)
ellipse(x, y, w, h) animS.ellipse(id, dur, x, y, w, h)
rect(x, y, w, h) animS.rect(id, dur, x, y, w, h)
line(x1, y1, x2, y2) animS.line(id, dur, x1, y1, x2, y2)
triangle(...) animS.triangle(id, dur, ...)
arc(...) animS.arc(id, dur, ...)

Every shape just needs an id and duration added!

What can you make?

  • Animated infographics – charts that draw themselves
  • Storytelling sketches – reveal elements over time
  • Logo animations – shapes assembling into a design
  • Whiteboard effects – like someone is drawing live

Learn more: wixette.github.io/p5.animS

Hand-Drawn Visuals

Why sketchy visuals?

There’s something charming about hand-drawn visuals. They feel personal, approachable, and human. From sketch notes to illustrated infographics, the imperfect quality of pen on paper has a warmth that clean digital shapes sometimes lack. What if you could give your p5.js sketches that same feeling?

  • Hand-drawn visuals feel personal and approachable
  • They add character to data visualisations and graphics
  • Transforms any sketch into something that looks hand-made

What is p5.scribble?

p5.scribble replaces your standard p5.js shapes with hand-drawn, wobbly versions. The effect is like someone drew your sketch with a pen on paper. It’s incredibly easy to use – you just swap your drawing function names. The roughness property controls how wobbly the lines are. This is a great way to give your project a distinctive, organic feel.

  • Replaces standard shapes with hand-drawn versions
  • Looks like pen on paper
  • Just swap rect() for scribbleRect()
  • github.com/generative-light/p5.scribble.js

Including p5.scribble

Download into your project folder (preferred):

  • p5.scribble.js
<script src="p5.scribble.js"></script>

Or load from the web:

<script src="https://cdn.jsdelivr.net/gh/generative-light/p5.scribble.js/p5.scribble.js"></script>

Basic usage

To use p5.scribble, you create a Scribble object and then call its drawing methods instead of the standard p5.js ones. The roughness property controls how wobbly the lines are – higher values mean more hand-drawn. The bowing property controls how curved the lines are. The method parameters are the same as p5.js, so it’s easy to convert existing code.

Sketchy bar chart

Here’s a practical example: a hand-drawn bar chart. This takes the data visualisation techniques from the previous lecture and gives them a completely different visual character. The data is the same, but the hand-drawn style makes it feel more personal and approachable.

What can you make?

  • Sketchy data visualisations – charts with personality
  • Comic-style graphics – panels, speech bubbles, characters
  • Prototype aesthetics – wireframe / napkin-sketch look
  • Mixed media – combine scribble shapes with photos or clean text

Wrapping up

Choosing a library

You don’t have to use any of these libraries for your project – they’re just tools that might help you. Think about what kind of project excites you and pick the library that fits. Or combine them! You could make a physics game with p5play that uses hand tracking from ml5.js, or a generative poem with RiTa that’s drawn in a sketchy style with p5.scribble.

Library Best for Complexity
p5play Games, physics, interactive art Low
ml5.js Webcam, body/hand tracking Low-Medium
RiTa.js Generative text, poetry Low
p5.animS Animated drawing effects Very low
p5.scribble Hand-drawn visual style Very low

You don’t have to use any!

Finding more libraries

We only covered five libraries today, but there are many more. The official p5.js libraries page is the best starting point – it lists dozens of community-made libraries for everything from 3D graphics to GUI controls to particle systems. Each one has a link to its documentation and source code.

  • The official list: p5js.org/libraries
  • Covers: GUI, particle systems, networking, accessibility, and more
  • Each entry links to documentation and examples
  • If you can think of it, there’s probably a library for it

Beyond p5.js

p5.js is a great starting point, but it’s not the only creative coding tool out there. If you get into creative coding, you might also want to explore three.js for 3D web graphics, Tone.js for advanced audio synthesis, matter.js for another physics engine, or D3.js for data visualisation. These are all JavaScript libraries that work in the browser, just like p5.js.

If you want to go further after this course:

  • three.js – 3D graphics in the browser
  • Tone.js – advanced audio synthesis
  • matter.js – another physics engine
  • D3.js – powerful data visualisation
  • Cables.gl – visual programming for WebGL
